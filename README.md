# App Online 

Projeto de e-commerce desenvolvido na disciplina git, Agile e Dev culture

## Como rodar

git clone https://github.com/Diocliin/app-online-ead.git
cd app-online-ead
npm install
npm start

## Estrutura

- /src - código da aplicação
- /testes - testes automatizados
- .github/workflows - pipeline de CI
